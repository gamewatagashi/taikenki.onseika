体験記 音声化バッチツール

Google Gemini TTSで体験記をまとめて読み上げ → WAV / M4A を書き出します。モデルとProjectを切り替え可能。

音声モデル 差し替え可能
GoogleのTTSモデルは同じAPI形式で切り替えられるため、将来の新しいGoogle TTSもモデルIDを変更して利用できます。
Google Project / API Key 複数登録可
APIキーは各Google Cloud / AI Studio Projectごとに登録してください。レート制限が発生したProjectだけを一時的に停止し、次のProjectへ切り替えます。
現在使用中：Project 1 状態：待機中
切替対象はレート制限系のHTTP 429のみです。400 / 401 / 403 / 500 / 503などでは別Projectへ自動切替しません。
⚠ APIキーの1日の利用上限に達しました
別のAPIキーをお持ちの場合は、上のAPIキー欄に貼り替えてから、エラーになった体験記を個別に「再生成する」ボタンで再試行してください。
「すべて音声化」を再度押すと、まだ完了していない件もまとめて再処理されます。
